# Competitor scan

Written from product knowledge of widely used apps as of 2026. This is a scan,
not a fresh usability study. The roadmap already took cues from MyStudyLife
(weekly overview, coursework workspace).

| App | Strengths | Weaknesses CampusFlow can beat |
| --- | --- | --- |
| MyStudyLife | Timetable with rotations, tasks/exams per class, cross-platform | Separate screens per type; no single daily plan; ads in the free tier |
| Power Planner | Grades/GPA, semesters, timetable, Windows/Android | Dated UI; iOS less polished; no campus events |
| myHomework | Simple homework list and class calendar | Thin feature set; premium-gated sync/widgets |
| Notion student templates | Infinitely flexible | Setup heavy; poor mobile capture; no reminders that work |
| Todoist / TickTick | Excellent capture, recurrence, reminders | Generic, so no classes, grades or study planning |
| Structured | Beautiful visual day timeline | No academic model; key features paywalled |
| Official U of A / campus apps | Authoritative info, maps, news | Not personal; no planning; often slow, portal-centric |

## Feature checklist for the MVP

| Feature | Status | Priority |
| --- | --- | --- |
| Class timetable with rooms/times | Done | Must-have |
| Assignments and exams per course with due dates | Done | Must-have |
| Unified daily view | Done (Today) | Must-have, our differentiator |
| Reminders for deadlines/classes | Done | Must-have |
| Grades and targets | Done | Must-have |
| Fast task capture and natural dates | Done | Must-have |
| Offline reading | Done | Must-have |
| Account, export, deletion | Done | Must-have (store requirement) |
| Campus events | Done (Augustana feeds) | Differentiator |
| Study session planning and focus timer | Done | Differentiator |
| Hosted, installable build anyone can get | **Missing** | Must-have |
| Self-service signup with email verification | **Blocked on mail provider** | Must-have |
| Demo account / sample data | **Missing** | Must-have for reviewers |
| Home-screen widgets | Missing | Nice-to-have |
| Import timetable from ICS file | Missing | Nice-to-have |
| Canvas sync | Fixture only (institution gate) | Nice-to-have until approved |
| Shared/group planning, social | — | Skip for MVP |
| Campus map, dining, transit | — | Skip (Camrose has no transit API; no verified dining feed) |
| AI planning, gamification | — | Skip for MVP |
